# 90_SideIdeas

A parking lot for ideas that are not part of Abracodabra's current design: a spin-off game, a feature that does not fit the pillars, a "what if" that deserves a few lines before it is forgotten.

**This folder is not the design of record.** The design of record is named in `01_Core/projectmemory.md` (Snapshot). Nothing here is scoped, costed or promised.

- One file per idea, `Name_YYYY-MM-DD.md`; edit in place, git keeps the history.
- Empty for now. `02_Design/Concepts/Gene_Catalog_Experimental_Annex_2026-07-20.md` is a concept pass, not a side idea, and stays in `Concepts/`.
- An idea that becomes real moves to `02_Design/Concepts/` (research) or `03_Tasks/Roadmap.md` (a candidate block). One that is dropped moves to `99_Archive/`.
